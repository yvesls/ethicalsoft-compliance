Por que precisamos do seu token? Os recursos de inteligência artificial do EthicalSoft Compliance (geração de insights, explicação dos resultados ISEP, relatório de risco e chat de perguntas e respostas) consomem a API da Groq Cloud. Para que você tenha total controle sobre o uso, o consumo e a privacidade dos seus dados, cada usuário utiliza sua própria chave pessoal.

Cadastrar seu token leva menos de um minuto, é gratuito e dá acesso imediato a todos os recursos de IA da plataforma.

Como protegemos seu token

  • Seu token é criptografado em repouso com AES-256-GCM antes de ser salvo no banco de dados.
  • Nunca exibimos seu token completo — apenas uma máscara como gsk_…Zn5tj.
  • O token é vinculado exclusivamente à sua conta e jamais é compartilhado com outros usuários.
  • Em todas as chamadas, seu token é enviado diretamente para a Groq Cloud.
  • Você pode remover seu token a qualquer momento, e a remoção é imediata.

Como obter sua chave Groq Cloud (gratuita)

  1. Acesse console.groq.com e crie uma conta.
  2. No painel lateral, abra API Keys e clique em "Create API Key".
  3. Dê um nome (por ex. "EthicalSoft Compliance") e copie a chave — começa com gsk_…
  4. Volte para esta tela, cole a chave no campo abaixo e clique em Salvar.
